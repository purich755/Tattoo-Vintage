# Tattoo Vintage — демо главной «Проявка»

Одностраничный демо-сайт тату-студии Tattoo Vintage (Краснодар, ул. Петра Метальникова, 28) для холодного предложения владельцам.
Метафора — аналоговая фотолаборатория при красном свете: включается фонарь → кадр проявляется → контактный лист → сушка → таймер → в футере включают белый свет.

## Запуск

Статика без сборки: HTML + CSS + vanilla JS (ES-модули). GSAP 3.13 (ScrollTrigger, Flip) и Lenis 1.3.11 — с jsDelivr, фиксированные версии, грузятся после `load`.

```bash
node tools/serve.mjs 8888
```

Конфиг `vintage` в общем `.claude/launch.json`. Для сайта нужен только `index.html`, `favicon.svg`, `css/`, `js/`, `assets/` — остальное (tools, raw, node_modules) рабочее.

## Где что править

- **`js/data.js`** — все факты, ссылки, цитаты, подписи, список фото. Имя мастера — константа `MASTER_F`. Спорные места помечены `// TODO_CONFIRM`.
- Список фото в `data.js` генерируется: `node tools/build-images.mjs` → `node tools/sync-photos.mjs`.
- Шрифты — локальные сабсеты Google Fonts (Cormorant Garamond, IBM Plex Mono, Manrope, Caveat): `node tools/fonts.mjs`. Один woff2 на начертание вместо пары latin+cyrillic, сайт не ждёт fonts.googleapis.com.
- Схема квартала для карты-заглушки — из OSM: `node tools/build-map.mjs` → `assets/svg/map.svg`.

Ширины 360 / 390 / 768 / 1024 / 1440 / 1920 — без горизонтального скролла, консоль чистая. `prefers-reduced-motion`: без прелоадера, Lenis, пинов, ряби, покачивания, зерна и бегущих строк.

## Отчёт по фото

**Источники** (полный список с оригиналами — `assets/img/SOURCES.md`, манифест — `assets/img/manifest.json`):

- **Яндекс Карты, галерея** — из 100 фото панель отдала 71 ссылку, скачано 70 оригиналов (`orig`, 1080–5712 px). Не скачалась одна — квадратный аватар-логотип. На сайте 24 кадра: хиро (рукав с ангелами, 1920×2381), почти весь контактный лист, два отпечатка «Сушки».
- **Telegram, t.me/s/tattoovintage888** — 250 постов, 155 фото и 98 превью видео; публичное превью отдаёт фото только до 800 px. На сайте 8 кадров: нога «±8 часов» (пост 330), внешний рукав (331), пирсинг (194), перекрытие (320), две пары до/после (320, 294).
- **Видео Telegram** — скачано 14 роликов процесса через embed постов. Ролик поста 280 → фон таймера (8 с, без звука, H.264 394 КБ + WebM 356 КБ). Кадры роликов 304 и 162 — руки мастеров, 280 — «Обучение».
- **ВКонтакте** — `m.vk.com/tattoo5632` без входа отдаёт только иконки интерфейса, альбомы закрыты. Не получено ничего; Яндекса и Telegram хватило.

**Что не вышло и какие фолбэки сработали:**

- **Портретов мастеров нет** → в кадре 03 руки за работой (кадры видео) и пометка «Портрет — в полной версии». Кто на каком кадре — не подтверждено.
- **Пост 364 «3 дня до раннего утра»** — видео больше лимита превью Telegram, не скачалось → в «Сушке» висит «засвеченный» отпечаток со ссылкой на пост.
- **Фото перманентного макияжа нет** ни в одном источнике → в списке услуг при наведении показывается «кадр не проявлен».
- **Третья пара до/после** (пост 138) — руки сняты по разным диагоналям, слайдер не совмещается. Оставлены две пары, обе кадрированы так, чтобы татуировки легли друг на друга. Telegram-фото маленькие (300–336 px по ширине после кадрирования) — для слайдера терпимо, для полной версии нужны оригиналы.
- Фото из Telegram в контактном листе (1 из 22) — лупа увеличивает версию 600 px, а не 2000.
- AVIF сжат с `quality 52` в sharp — по картинке это соответствует 78–82 у WebP/JPG; при `quality 80` AVIF выходит тяжелее WebP.

## Решения вне брифа

- **Хостинг.** В брифе Vercel, но `*.vercel.app` в РФ блокируется — владельцы без VPN ссылку не откроют. Предлагаю GitHub Pages: сайт полностью статический, переносится без изменений.
- **Карта.** По клику грузится виджет Яндекс Карт без организации (`pt=`), как в брифе. В таком виджете бывает рекламный слот внизу. Звёзд рейтинга там нет — их показывает только виджет с `oid`.
- **`noindex`** — демо не должно попадать в поиск вместо будущего настоящего сайта. Перед запуском убрать.
- **JSON-LD `TattooParlor`** — только проверенные поля: без рейтинга и без часов работы.
